# Global Stock Ticker for KDE Plasma 6 (全球股市行情挂件)

适用于 **KDE Plasma 6** 任务栏/顶栏面板的实时股票与基金行情挂件。支持国内 A 股、ETF、大盘指数、港股、美股以及加密货币，具备极简省空间的面板设计、行内折叠、交易时段智能节流与红涨绿跌高亮。

---

## 🌟 核心特性

- 📈 **面板行内一键折叠 / 展开 (In-place Expand & Collapse)**：
  - **小图标形态 (折叠)**：仅占用任务栏一个图标槽位（约 28×28 像素），显示精致的 📈 图标；
  - **即时行情悬停卡片**：在折叠状态下，鼠标悬停于小图标 📈 即可在气泡弹窗中直接查看所有自选股的最新价格与涨跌幅快照，无需展开；
  - **点击一键互转**：点击展开模式即可瞬间折叠为图标；点击小图标 📈 即可平滑展开，并自动刷新最新行情。
- ↕️ **双显示模式自选**：
  - **上下翻滚 (垂直轮播 - 推荐)**：单条紧凑展示（宽度仅 ~165px，极省横向面板空间），每隔数秒平滑向上滑动切换下一只股票；
  - **横向跑马灯 (水平无限平滑滚动)**：经典多股排成一串平滑滚动，速度可自定义。
- 🎨 **清爽白边美化与边框定制**：
  - 提供 **白色高亮边框 (White Border)**、**无边框 (Borderless)** 及 **跟随系统主题 (System Theme)** 三种边框风格。
- 🌐 **多数据源智能切换与自动 Fallback**：
- ⏰ **交易时段智能节流 (省电省流量)**：
  - 支持设置**仅在交易时段自动刷新**（默认开启：早市 `09:25 - 11:30`，午市 `13:00 - 15:05`，周六/周日休市）；
  - 休市期间自动停止定时网络请求，静态保留最后收盘快照与缓存，并显示休市提示；
- 🖱️ **便捷交互与 Plasma 菜单**：
  - 左键单击展开框：快速折叠为小图标（或可在设置中改为点击刷新）；
  - 鼠标滚轮中键单击：随时强制触发一次即刻刷新；
  - 原生右键菜单：支持右键菜单一键刷新与切换折叠/展开；
  - 鼠标悬停：自动暂停滚动，方便细看。
- 🇨🇳 **自选颜色与中文名称**：
  - 支持中文简称显示（如 `工业富联`、`贵州茅台`）；
  - 支持**红涨绿跌**（中国大陆习惯）、**绿涨红跌**（国际市场习惯）及单色风格自由切换。

## 💻 股票与标的代码格式

| 市场类别 | 代码格式示例 | 说明 |
| :--- | :--- | :--- |
| **A股 / ETF** | `601138`, `600519`, `000001`, `510300` | 直接输入 6 位纯数字代码，自动识别沪深市场 |
| **大盘指数** | `1.000001` (上证), `0.399001` (深成指), `0.399006` (创业板) | 前缀带市场代码（1为沪，0为深） |
| **港股** | `116.00700` (腾讯), `116.09988` (阿里) 或 `00700` | 前缀 `116.` 或直接输入 5 位代码 |
| **美股** | `105.AAPL`, `105.TSLA`, `105.NVDA` 或 `AAPL` | 前缀 `105.` 或直接输入美股代码 |
| **加密货币** | `BTC-USD`, `ETH-USD` | （使用雅虎财经数据源） |

## 🛠️ 安装与更新使用

### 1. 首次安装

在克隆或下载的仓库根目录下执行：

```bash
kpackagetool6 --type Plasma/Applet -i package
```

### 2. 更新升级

当拉取最新代码后，执行热更新：

```bash
kpackagetool6 --type Plasma/Applet -u package
```

### 3. 重启面板生效

KDE Plasma 会在内存中缓存已加载的 QML 实例，运行以下命令重启桌面面板即可生效：

```bash
systemctl --user restart plasma-plasmashell
```

### 4. 添加到任务栏

1. 在 KDE 任务栏面板空白处右键 -> 选择 **添加部件 (Add Widgets)**；
2. 搜索 `Global Stock Ticker` 或 `全球股市`，将其拖动到任务栏任意位置；
3. 右键部件进入 **配置 (Configure)**，即可自由设定股票列表、数据源、显示模式及交易时段。
